# Shop Manager - Screenshots Guide

This guide explains how to create professional screenshots and marketing images for Shop Manager.

## Screenshot Requirements

### Dimensions
- **Website/Landing Page:** 1920x1080 (16:9)
- **Social Media (Twitter/Facebook):** 1200x630
- **App Store Screenshots:** 2732x2048 (iPad Pro), 2778x1284 (iPhone)
- **Documentation:** 1440x900 or 1920x1200

### Quality Standards
- **Resolution:** At least 1920px wide for web
- **Format:** PNG (for UI screenshots), JPG (for photos)
- **Color Profile:** sRGB
- **Compression:** Optimized but not overly compressed

## Editing Guidelines

### Annotations
- **Arrows:** Use brand color (#667eea)
- **Highlights:** Yellow (#FFC107) with 50% opacity
- **Text:** Sans-serif font, 16-18px
- **Blur:** Blur sensitive data (never fake it)

### Cropping
- Leave 20-40px margin around UI elements
- Align to grid (8px or 16px)
- Keep important elements in center
- Maintain aspect ratio

### Optimization
```bash
# Using ImageOptim (macOS)
imageoptim screenshot.png

# Using pngquant (command line)
pngquant --quality=65-80 screenshot.png

# Using TinyPNG (online)
# Upload to https://tinypng.com
```

## Data Privacy

### ⚠️ IMPORTANT: Never Use Real Data

**DO:**
- ✅ Use fictional company names (ACME Corp, Demo Store)
- ✅ Use fake email addresses (john@example.com)
- ✅ Use placeholder phone numbers (555-0100)
- ✅ Use generic product names (Product A, Item 123)
- ✅ Use test payment info (**** 1234)

**DON'T:**
- ❌ Show real customer names
- ❌ Show real transaction IDs
- ❌ Show real addresses
- ❌ Show real payment details
- ❌ Show real inventory data

## Creating Animated Screenshots (GIFs)

### Tools
- **macOS:** Kap (free), Gifox ($15)
- **Windows:** ScreenToGif (free), LICEcap (free)
- **Cross-platform:** OBS Studio + ffmpeg

### Best Practices
- Keep under 5 seconds
- Max 10 MB file size
- 60fps for smooth animation
- Optimize with gifsicle or ezgif.com
- Show one feature per GIF
- Loop seamlessly

### Example GIFs to Create
1. **Quick checkout:** Scan product → Add to cart → Complete sale (3s)
2. **Add product:** Click Add → Fill form → Save → Product appears (4s)
3. **Low stock alert:** Stock reaches threshold → Alert appears → Notification (3s)

## Automation Script

Create consistent screenshots automatically:

```bash
#!/bin/bash
# screenshots.sh - Automated screenshot capture

# Set browser to full HD
osascript -e 'tell application "Google Chrome"
    set bounds of front window to {0, 0, 1920, 1080}
end tell'

# Navigate to each page and capture
pages=(
    "http://localhost:3001/dashboard:dashboard.png"
    "http://localhost:3001/pos:pos.png"
    "http://localhost:3001/inventory:inventory.png"
    "http://localhost:3001/analytics:analytics.png"
)

for page in "${pages[@]}"; do
    url="${page%%:*}"
    filename="${page##*:}"

    # Open page
    open "$url"
    sleep 3

    # Capture
    screencapture -x "screenshots/$filename"
done

echo "Screenshots captured!"
```
